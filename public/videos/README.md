производство» — принадлежность не подтверждена.

## Как подключать

```jsx
<video
  src="/videos/process-sewing.mp4"
  poster="/videos/process-sewing-poster.webp"
  muted playsInline loop preload="none"
  width={864} height={486}
  aria-label="Сборка плюшевой игрушки на производстве"
/>
```

- `preload="none"`; запуск только когда элемент виден (IntersectionObserver), пауза при уходе из зоны видимости.
- Звука нет и не добавлять. Рядом всегда текст: ролик не единственный носитель смысла.
- При `prefers-reduced-motion: reduce` видео не запускается — показываем постер как обычную картинку.
- Только ниже первого экрана: в LCP видео не участвует.
