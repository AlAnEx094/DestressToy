# Интеграция калькулятора с Telegram

## Адрес калькулятора

Внутренняя страница:

`https://destresstoys.ru/tools/cost-calculator`

Адрес для конкретной сделки:

`https://destresstoys.ru/tools/cost-calculator?dealId=recXXXXXXXX`

## Защита доступа

Калькулятор закрыт на уровне Vercel Middleware.

Открыть его можно только по ссылке с access-token:

`https://destresstoys.ru/tools/cost-calculator?dealId=recXXXXXXXX&access=SECRET_TOKEN`

При первом открытии middleware:

1. проверяет `access`;
2. ставит защищённую HttpOnly-cookie;
3. редиректит на чистый URL без токена;
4. дальше страница открывается по cookie.

Если токена или cookie нет, сервер возвращает `404`.

## Что нужно сделать в Vercel

Добавить environment variable:

- name: `CALCULATOR_ACCESS_TOKEN`
- value: длинный случайный токен
- environments: Production, Preview, Development по необходимости

Пример генерации токена локально:

```powershell
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

После добавления переменной нужно redeploy проекта.

## Как связать с Telegram

В n8n в сообщении владельцу нужно добавить кнопку или ссылку:

`https://destresstoys.ru/tools/cost-calculator?dealId={{ $json.dealId }}&access={{ $env.CALCULATOR_ACCESS_TOKEN }}`

Лучшее место для кнопки:

- уведомление после готового превью;
- уведомление после ручного статуса `✅ Дизайн одобрен`;
- отдельная команда бота `/calc recXXXXXXXX`.

## Рекомендуемый сценарий

1. Клиенту понравилось превью.
2. Ты переводишь сделку в `✅ Дизайн одобрен`.
3. n8n присылает тебе Telegram-сообщение: “Пора запросить поставщиков”.
4. В этом же сообщении есть кнопка “Открыть калькулятор”.
5. Ты общаешься с поставщиками вручную.
6. Получаешь EXW, форму, печать, упаковку, вес, сроки.
7. Открываешь калькулятор из Telegram.
8. Считаешь стоимость.
9. Копируешь расчёт и переносишь его в Airtable/КП.

## Следующий этап

Следующим шагом можно добавить webhook `save-cost-calculation`, чтобы кнопка “Сохранить расчёт” записывала в Airtable:

- `Стоимость формы ₽`
- `Стоимость покраски/печати ₽`
- `Стоимость доставки ₽`
- `Итоговая себестоимость ₽`
- `Цена клиенту расчёт ₽`
- `Наценка %`
- `Последнее сообщение клиенту`
- статус `📋 КП выставлено` или `🧮 Расчёт себестоимости`
